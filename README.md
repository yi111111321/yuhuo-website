## 现在这版是什么

结构参照凡科「户外广告」企业模板（`ol31682075.jzfkw.net`），配色改为中国红：

```
顶部信息条 → 头部导航 → 轮播 Banner（3 张）
→ 四宫格优势 → 红色数据条 → 试点单位
→ 产品中心 → 核心技术 → 实证案例 → 资质荣誉
→ 新闻资讯 → 公司简介 → 联系我们 → 页脚
```

动效：Banner 自动轮播（6.5s / 可点圆点 / 悬停箭头）、区块滚动淡入、卡片 hover、导航滚动高亮。
